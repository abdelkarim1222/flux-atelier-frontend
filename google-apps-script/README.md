# Archive de l'ancien connecteur

`Code.gs` appartient à l'ancienne intégration Google Sheets. Il est conservé comme référence pour comprendre les traitements métier passés, mais l'application actuelle ne le charge pas et ne l'appelle pas.

Le flux actif est désormais : interface React → API Node.js (`server/index.mjs`) → PostgreSQL. Ne redéployez pas ce script pour lancer la nouvelle version.
